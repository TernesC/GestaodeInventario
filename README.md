# 📦 Gestão de Inventário

Um sistema moderno, leve e simples para gestão de inventário de TI desenvolvido com **Google Apps Script** e **HTML**, integrado diretamente com o **Google Sheets** e **Google Drive**.

Ideal para equipas de suporte, infraestrutura e gestão de ativos que precisam de um controlo simples, rápido e centralizado sem custos com servidores dedicados.

**Funcionalidades**
- Interface SaaS Moderna: Painel lateral (Sidebar), tabela de dados responsiva e indicadores visuais de estado (Badges).

- Busca Avançada e Filtragem: Campo de pesquisa dinâmica com seleção de filtro por Nome do Item, Serial, Património ou Observação.

- Ordenação de Colunas: Possibilidade de ordenar qualquer coluna por ordem alfabética ou numérica com um clique.

- Edição em Tempo Real: Alteração de quantidades, localizações e observações com gravação automática no banco de dados.

- Gestão por Categorias: Organização dedicada para Notebooks, Desktops, Telemóveis/Celulares, Periféricos e Outros.

- Banco de Dados na Nuvem: Sincronização direta com uma folha de cálculo no Google Sheets hospedada no Google Drive.

**Tecnologias Utilizadas**
- Backend: Google Apps Script

- Database: Google Sheets

- Frontend: HTML5, CSS3, JavaScript (ES6)

**Pré-requisitos**
- Uma conta Google.

- Uma folha de cálculo no Google Sheets estruturada para receber os dados.

- Acesso ao Google Apps Script vinculado à folha de cálculo.

**Como Configurar o Projeto**
= Abra a sua folha de cálculo no Google Sheets.

- Aceda ao menu Extensões > Apps Script.

- Crie os ficheiros do projeto:

Code.gs: Insira as funções do servidor em Apps Script.

index.html: Cole o código HTML do projeto.

- Faça o Deploy como Aplicação Web:

- Clique em Apresentar > Nova Apresentação.

- Selecione o tipo Aplicação Web.

- Defina quem tem acesso ao projeto e clique em Apresentar.

- Copie o URL gerado e abra no seu navegador!
